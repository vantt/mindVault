D5 · Place survives lockRoute + wizard draft, never secrets. Yes.
D6 · Auto fingerprint promptOnce per lock event. Yes.

D8 · Secret part managementAdd part now; change master after crypto review.
D9–D12Offline w/o Sheet ID · saved language · share-in intent · row copy. Yes.
D13 · Palette D — DECIDEDDark (= A Ink+Amber) and Linen light, equal first-class, follow system (System/Dark/Light setting). Calm via restraint: one amber main action per screen, faint vignette, no copy-sweep glow. Light uses accent-ink #8a5610 + button edge. Yes.
D14 · Plain words in UIPasswords · Enter code · Settings · Secret part · Written code · Private vault. Cooking = brand tagline only; narrow AGENTS.md protocol. Code syntax stays visible. Yes.
D15 · Secret parts 1–5 — DECIDEDUser picks how many (1–5) in setup and Settings. Same limit as engine/extension.
D16 · Align extension + landing terms — DECIDEDSame plain terms + wordmark without dot. Yes, separate plan.
D17 · Multiple secret-part sets on Android — DECIDEDMirror extension Profiles: each sheet bound to a set (Settings › Sheets › sheet › Secret parts set). UI hides sets while only one exists; gloss adds “· Family set” when ≥2. Fixes RECIPE_MISMATCH across sheets. Yes, phase 05; needs vault format change (existing vault migrates to one set “Default”).
Proposal boards, not device screenshots. Security invariants unchanged: FLAG_SECURE, 5/10 min lock, 10s reveal, 30s owned clipboard clear, no secrets in saved state. Spec: plans/261110-android-ux-flow-redesign/ux-flow-redesign-spec.md.
