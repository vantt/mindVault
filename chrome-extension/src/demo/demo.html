mindVault

Turn recipes into passwords

The Idea

Storing passwords in a spreadsheet means one breach exposes everything. mindVault flips this — you store recipes, not passwords. A recipe is a short code that tells the extension how to build your password, using a secret only you know.

Recipe (public) r4nd0m#1
Your secret #1 Basic*
Password Basic*r4nd0m

💡 Your spreadsheet can be public. The password is never stored anywhere — it's computed fresh each time from the recipe + your secret.

Position symbols — hash = abc, secret = XYZ

Symbol Meaning Result
# Prefix — secret first XYZabc
$ Suffix — secret last abcXYZ
@ Middle — secret in centre aXYZbc
% Interleave 1-by-1 aXbYcZ
^ Interleave 2-by-2 abXYcZ

Modifiers

Append optional modifier symbols after the position symbol to transform the output. Modifiers can be combined.

Symbol Effect Example
_ Flip — swap prefix and suffix behaviour #_ acts like $
! Uppercase — capitalise the secret basic → BASIC
? Reverse — reverse the secret string XYZ → ZYX
~ Strip — remove non-alphanumeric chars X!Y@Z → XYZ
Recipe with modifiers: r4nd0m#1!? ← hash r4nd0m, position #, secret 1, then modifiers !?

Daily Use

  1. 1
    Open your Google Sheet

    Your spreadsheet holds recipes — short codes like fb#1 or gh$2!.

  2. 2
    Click a cell with a recipe

    The selected cell value is read automatically by mindVault.

  3. 3
    Open mindVault

    Click the extension icon or press Ctrl+Shift+L (Mac: ⌃⇧L).

  4. 4
    Copy & paste

    Hit Copy and paste into the login field. Done.

🔄
Rotating a password? Update only the recipe hash — e.g. change fb#1 to fb2#1. Same secrets, completely different password. No secret changes needed.
