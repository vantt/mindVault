# 00 — Design Tokens (shared)

Tokens dùng chung cho tất cả screens. Không thay đổi từ v1, chỉ thêm `--readonly`.

```css
--bg-color:       #0d1117
--card-bg:        #161b22
--text-primary:   #f0f6fc
--text-secondary: #8b949e
--accent:         #58a6ff
--accent-hover:   #1f6feb
--border:         #30363d
--danger:         #da3633
--success:        #238636
--warning:        #d29922
--readonly:       #21262d   /* new — shared/readonly bg */
```

**Font:** Outfit (Google Fonts), weights 300/400/500/600
**Container width:** 600px
**Border-radius cards:** 12px
**Border-radius inputs/buttons:** 6px

**Profile color dots (cycle):** `#58a6ff` · `#e3b341` · `#3fb950` · `#a371f7`
