## Feature Boundary

Port the extension's recipe-generation engine and full-access-bundle decryption to a new Kotlin Multiplatform (KMP) shared module (Android + JVM targets only), and prove Argon2id parity between KMP and the extension's WASM implementation — no OAuth, no Sheets API, no UI screens in this slice.

## Terms

| Term | Meaning in this feature |
|------|-------------------------|
| Recipe | The user-facing string (e.g. `r4nd0m#1`) that a hash + position + secret-index + modifiers + optional tag parse out of, per `RegexParserAdapter`. |
| Full-access bundle | The JSON object `createFullAccessBundle` produces: `{type, version, bundleId, profileName, exportedAt, sheetId, encryptedData, iv, exportSalt}`, AES-GCM-encrypted with a PBKDF2-derived key. |
| Golden test | A test marked `// @approved` in `chrome-extension/test/unit/generate_password.spec.mjs` — source-of-truth output the KMP port must reproduce byte-for-byte (per `AGENTS.md` Test Case Protocol). |

### Reusable Assets

- `chrome-extension/src/adapters/infrastructure/regex_parser_adapter.js:1-39` — `RegexParserAdapter`, recipe grammar `<hash><position><secretIndex>[modifiers][.tag]`, regex at line 16, `parse(text)` at line 23.
- `chrome-extension/src/core/domain/tag-codec.js:1-113` — `TAG_ALPHABET`/`TAG_LENGTH`/`TAG_REGEX`, `canonicalize()`, `computeRecipeTag()` (HMAC-SHA256, base32, truncated to 4 chars), `verifyRecipeTag()`. Tag is verification-only, does not affect the password value.
- `chrome-extension/src/core/usecases/generate_password.js` — `GeneratePassword.execute()` (line 20); `_combine(hash, position, secret)` (lines 62-74, pure string ops per position `#$@%^`); `_interleave()` (lines 76-83). Confirmed no Argon2 call here (matches D1's rationale).
- `chrome-extension/src/adapters/infrastructure/argon2_adapter.js:1-56` — `Argon2Adapter.deriveKey()`, params: Argon2id, hashLen 32, time 3, mem 65536 (64MB), parallelism 4. Used only for unlock-key derivation, not password generation.
- `chrome-extension/src/adapters/infrastructure/export-import-adapter.js` — `PBKDF2_ITERATIONS = 100000` (line 12), `deriveKeyFromPassword()` (line 33, PBKDF2-SHA256 → AES-GCM 256-bit key), `createFullAccessBundle()` (lines 95-115, random 12-byte IV, 16-byte salt), `decryptBundle()` (lines 155-168).
- `chrome-extension/src/options/options-import-wizard.js:153` — the extension's own bundle-decrypt consumer (`validateBundle` then `decryptBundle`); the KMP decrypt flow mirrors this call shape.
